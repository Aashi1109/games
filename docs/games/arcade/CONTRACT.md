# Arcade game integration

Each game is an ES module exporting `mount(host, api)` and returning a cleanup function. Its DOM belongs entirely inside host. Do not edit shared files outside your assigned games/tests. Native JS only, no external dependencies.

API: `api.setStats([{label:'Score',value:12}, ...])`; `api.setHint('Instructions')`; `api.sound('tap'|'good'|'win'|'lose')`; `api.isPaused()`; `api.finish({title:'Nice run!',message:'A brief result.',score:100,unit:'points'})`; `api.getBest()`; `api.save(key,value)`; `api.load(key,fallback)`. finish shows shared results overlay and replay/home actions, and updates high score. All games higher score is better. No private persistence/global listeners without cleanup. A shared Pause/Resume and Restart button is provided. Return cleanup for all listeners, animation frames, timeouts and observers.

Shared helpers from `../lib/core.js`: `clamp(n,min,max)`, `seeded(seed)` returns rng, `shuffle(array,rng=Math.random)`, `daySeed()` YYYY-MM-DD UTC string, `createCanvas(host,width=960,height=600)` -> `{canvas,ctx,width,height,point(event),destroy()}`; ctx coordinates logical and DPR-aware. `animate(tick)` -> stop callback; tick(dtSeconds,elapsedSeconds); check api.isPaused() yourself. `listen(target,type,handler,options)` -> cleanup. `roundRect(ctx,x,y,w,h,r,fill,stroke)`; `drawText(ctx,text,x,y,size,color,align='left',weight=700)`. Fonts `'Trebuchet MS', sans-serif`. Use canvas logical width/height. A .game-board CSS class and .game-controls/.game-control/.game-action/.game-note styles exist. DOM puzzles use .puzzle-layout/.puzzle-board/.puzzle-aside and provide local style with unique game prefix if necessary.

Visual: tactile, art-directed, clean. Warm off-white/ink UI around each scene; own thematic game palette. Distinctive illustrated backgrounds and charming characters rendered with custom canvas/SVG. Rounded geometry, strong contrast, crisp outlines. No emoji as primary artwork, stock charts, glowing generic sci-fi, or placeholder text. Touch controls required for action games; keyboard support for all games. Reduced motion preference honored for decorative particles. Mobile width 360px. No horizontal overflow. No autoplay audio until user gesture. Keep controls labeled and accessible. Play starts when mounted after explicit Start button; end only once; restart mounts a fresh game.

Games must be complete playable loops with clear objectives, proper win/loss, restart, increasing challenge or multiple levels, and feedback. Export pure logic where useful, add focused Node tests of real rule invariants. No fake score/test-only win button.
